# Steady with Shane — funnel

Single-page interactive landing page.

## Deploy on Vercel
1. Create a new Vercel project.
2. Upload this folder (`index.html` + `shane.jpg`).
3. Deploy. Root directory should contain `index.html`.

Or from CLI:
```bash
npx vercel --yes
```

## Swap photo
Replace `shane.jpg` with another square portrait if you want the original neon version (`shane-original.jpg` is included).
